# Games View

All RWA games in the *rwaclient Files folder* on your iPhone (accessible in Finder through the *Files* tab when connecting the device to your laptop) will appear in this list view.

Tapping on the list entry will launch that game into [Control Data View](./control-data-view.md), where you can start the game.

The game that has the setting *Default Game* enabled, will launch automatically when you start the app the next time.
